# Plugin

`agentkit/plugin` 在 Runner 生命周期注入横切能力：安全护栏、日志、工具搜索、错误格式化等。

## Plugin 接口

```go
type Plugin interface {
    Name() string
    // 在 agent 运行前后、工具调用前后等钩子点执行
}
```

通过 `runner.WithPlugins(p1, p2, ...)` 注册，按顺序组成插件链。

## Guardrail 安全护栏

| 子包 | 功能 |
|------|------|
| `plugin/guardrail/promptinjection` | 提示注入检测 |
| `plugin/guardrail/unsafeintent` | 不安全意图检测 |
| `plugin/guardrail/approval` | 人工审批（Human-in-the-loop） |

```go
import "github.com/LingByte/ling-base/agentkit/plugin/guardrail/approval"

ap := approval.New(approval.Config{
    OnApprovalRequired: func(ctx context.Context, req approval.Request) (bool, error) {
        // 返回 true 允许执行
        return askUser(req), nil
    },
})
r := runner.NewRunner("app", ag, runner.WithPlugins(ap))
```

| `plugin/errormessage` | 自定义错误文案 |

## 自定义 Plugin

```go
type MyPlugin struct{}

func (p *MyPlugin) Name() string { return "my-plugin" }
// 实现 EventHook 接口方法 ...

r := runner.NewRunner("app", ag, runner.WithPlugins(&MyPlugin{}))
```
