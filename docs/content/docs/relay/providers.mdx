## 使用方式

```go
import "github.com/LingByte/ling-base/relay/channel/openai"

provider := openai.NewProvider("sk-xxx")
// 或自定义 baseURL
provider := openai.NewProviderWithBase("sk-xxx", "https://api.your-proxy.com")

client := relay.New(relay.WithProvider(provider))
```
