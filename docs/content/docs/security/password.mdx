# 密码哈希

## 安装

```bash
go get github.com/LingByte/ling-base/common/password
```

## 哈希密码

```go
import "github.com/LingByte/ling-base/common/password"

// 默认使用 argon2id
hash, err := password.Hash("mypassword")
// $argon2id$v=19$m=65536,t=3,p=2$xxx$xxx
```

## 验证密码

```go
err := password.Verify("mypassword", hash)
if err == nil {
    // 密码正确
}
```

## 自定义算法

```go
// bcrypt
hash, _ := password.HashWith("mypassword", password.Bcrypt)

// scrypt
hash, _ := password.HashWith("mypassword", password.Scrypt)

// argon2id（默认）
hash, _ := password.HashWith("mypassword", password.Argon2id)
```

## 密码强度检查

```go
err := password.CheckStrength("weak")
// err: 密码太短

err := password.CheckStrength("MyStr0ng@Pass123!")
// nil: 强度足够
```
