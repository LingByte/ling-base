## 安装方式

每个子包独立 module：

```bash
go get github.com/LingByte/ling-base/common/logger
go get github.com/LingByte/ling-base/common/cache/lru
go get github.com/LingByte/ling-base/common/bloom/memory
```

在 monorepo 内开发时通过 `go.work` 引用本地路径即可。
