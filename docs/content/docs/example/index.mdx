# 示例与脚手架

仓库根目录的 `example/` 已清空并预留，不再提供 `example/cmd/*` 演示程序，也不再作为 Go 工作区模块。需要可运行的项目骨架时，请使用 [lingcli](/docs/lingcli)。

## relay 示例

`relay/example/` 中的示例继续保留，不受根目录 `example/` 清理影响：

| 路径 | 说明 |
|------|------|
| `relay/example/basic` | 基础 Chat |
| `relay/example/realtime` | Realtime WebSocket |
| `relay/example/gemini` | Gemini channel |
| `relay/example/midjourney` | Midjourney 异步任务 |
| `relay/example/suno` | Suno 音乐生成 |

在仓库根目录运行，例如：

```bash
go run ./relay/example/basic
```

部分示例需要配置对应服务的 API Key 或环境变量。详见 [relay 示例说明](https://github.com/LingByte/ling-base/tree/main/relay/example)。

## 创建独立项目

```bash
lingcli create myapp
```

`lingcli` 支持 Web API、gRPC、CLI、库和 Worker 等项目模板，可按需集成 ling-base 模块。见 [项目模板](/docs/lingcli/templates)。
