语音能力位于 `providers/voice`：

```
providers/voice/
├── recognizer/    # ASR
├── synthesizer/   # TTS
├── realtime/      # 实时多模态
├── vad/
├── voiceprint/
└── voiceclone/
```

```bash
go get github.com/LingByte/ling-base/providers/voice/recognizer
go get github.com/LingByte/ling-base/providers/voice/synthesizer
go get github.com/LingByte/ling-base/providers/voice/realtime
```
